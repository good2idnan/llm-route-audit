# routeaudit Roadmap

> routeaudit replays a sample of your real AI traffic on cheaper (model, effort) options and grades the answers. It then tells you whether routing would save money without hurting quality, and exports the winning policy as a table your existing gateway can load.

## Principles

- **Prove it before you route.** Every recommendation is compared with these baselines:
  - "always the strongest model"
  - "strongest model at low effort"
  - "always the cheapest model"
- **No surprise spend.** Show a cost estimate and ask for confirmation before any paid replay.
- **Readable output.** The policy is a plain YAML table, not a black box.
- **Local first.** Logs never leave the user's machine except for the model calls the user approves.
- **Complement, don't compete.** Work alongside LiteLLM, OpenRouter and other gateways; don't replace them.

## M1: v0.1 "First audit" (weeks 1–3)

**Log format**
- [x] Define the JSONL record with these fields (done in M0):
  - required: `id`, `timestamp`, `messages` or `prompt`, `response`, `model`
  - optional: `input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_write_tokens`, `latency_ms`, `task_type`, `outcome`, `metadata`
- [x] Pydantic models and validation, with clear errors that give the line number (`routeaudit validate`)

**`routeaudit analyze`**
- [ ] Traffic profile: request count, token totals, current cost, cost by model
- [ ] Task-type mix: use `task_type` when present; otherwise label each request with a cheap model against a fixed taxonomy plus `other`

**`routeaudit replay`**
- [ ] Candidates file listing (model, effort) pairs
- [ ] Sample stratified by task type (`--sample N`)
- [ ] Show the cost estimate and require confirmation (`--yes` skips the prompt)
- [ ] Provider adapters: Anthropic (official SDK), OpenAI (official SDK), Ollama (local HTTP)
- [ ] SQLite result cache so the same replay is never paid for twice
- [ ] Retries, rate-limit handling and resume after interruption

**Grading**
- [ ] Deterministic checks: valid JSON, matches the JSON schema, regex, exact match, length limits
- [ ] Pairwise AI judge that compares each candidate with the reference answer
  - [ ] Judge both answer orders and count disagreement as "tie / uncertain"
  - [ ] Report judge agreement in the output
- [ ] Optional file of human labels that overrides the judge

**Cost and policy**
- [ ] Cache-aware cost model built from `prices.yaml`
- [ ] Baselines: always-strongest, strongest-at-low-effort, always-cheapest, the user's current mix
- [ ] Per task type, choose the cheapest candidate whose quality stays within the threshold (default 97% of baseline)
- [ ] Bootstrap confidence intervals for both quality and cost

**`routeaudit report` and `routeaudit export`**
- [ ] A single self-contained HTML report containing:
  - the cost/quality chart with the frontier
  - a per-task table
  - the baselines
  - judge agreement
- [ ] YAML policy export

**Done when:** v0.1 runs end-to-end on the bundled sample, shows its cost before spending, produces a report that opens offline, and passes tests in CI.

## Risks

| Risk | Mitigation |
|---|---|
| Replays cost money | Stratified sampling, Batch API, an upfront estimate and confirmation, and the result cache |
| AI judges are noisy or biased | Exact checks first, both answer orders, reported agreement, optional human labels |
| Agent sessions can't be replayed faithfully | v0.1 covers single-request workloads only; agents are deferred to M5 |
| Logs contain user data | Everything runs locally, with an opt-in redaction step |
| Prices and models change fast | Prices live in config, and `check-model` makes re-testing one command |
